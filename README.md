# Jonathan Simone

Independent AI researcher and systems developer. Founder of [Simone Systems Research](https://simoneresearch.com).

I build verification engines, approval planes, and evaluation harnesses that keep autonomous AI software grounded in primary evidence.

## Systems & Research

- **[Consumption Engine](https://simoneresearch.com/product/consumption-engine/)**: Evidence-linked knowledge infrastructure that preserves project sources, carries relevant evidence into agent tasks, and revisits work when sources change. Synthetic studies showed source-linked instructions helping agents follow project rules; the next milestone is reliable benefit on real tasks under qualified comparisons. Includes the [public synthetic fixture](https://github.com/thisisntjon/ce-stranger-replay-v1/tree/8374bb6ee93edef37f57f284532d9487d5fd2e2d), [research record](https://github.com/thisisntjon/consumption-demo), and [latest findings](https://simoneresearch.com/evidence/progress/).
- **[BigBoss](https://github.com/thisisntjon/bigboss-approval-plane)** ([v0.1.0](https://github.com/thisisntjon/bigboss-approval-plane/releases/tag/v0.1.0)): Deterministic approval dashboard and immutable decision plane for AI agent execution. Cross-platform CI on Ubuntu and Windows across Python 3.12 and 3.13 with [399 passing tests](https://github.com/thisisntjon/bigboss-approval-plane/actions/runs/35043376854).
- **[The Council](https://github.com/thisisntjon/thecouncil)**: Multi-model evaluation architecture for cross-examining claims, peer critique, and verifiable synthesis across disparate LLM providers. Includes inspectable examples and an offline test fixture.
- **[Pokémon TCG Research](https://github.com/thisisntjon/poketcg-research)**: Reinforcement learning architecture and search policy optimization. Implemented a combined counter with measured gains of about 19-20 percentage points against two tested Alakazam implementations.
- **[SEED Protocol](https://github.com/thisisntjon/seed-protocol)**: Empirical evaluation methodology separating autonomous agent activity from verifiable engineering progress. An author-run census of 1,979 agent fleet commits found 43.2% documentation-only churn, showing why merge volume alone is a poor proxy for progress.

## Engineering Standards

- **Public Retractions**: Claims are held to strict falsifiability. [The Bus](https://github.com/thisisntjon/thebus) was retired after an evaluation sweep invalidated 17 core architectural assumptions; its retraction ledger remains public.
- **Human Authority**: I direct all research questions, systems architecture, and verification. AI models assist implementation, testing, and drafting under strict empirical gating against primary evidence.
